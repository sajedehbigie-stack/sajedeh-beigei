# وب‌سایت هنرستان حاتمی ورزنه

## اجرای محلی
فایل `index.html` را در مرورگر باز کنید.

## انتشار با GitHub Pages
1. تمام محتویات این پوشه (خود فایل‌ها، نه پوشه‌ی والد) را در ریشه‌ی یک مخزن GitHub بارگذاری کنید.
2. در مخزن وارد **Settings → Pages** شوید.
3. در بخش **Build and deployment** گزینه‌ی **Deploy from a branch** را انتخاب کنید.
4. شاخه‌ی `main` و پوشه‌ی `/ (root)` را انتخاب و ذخیره کنید.
5. پس از پایان انتشار، نشانی GitHub Pages در همان بخش نمایش داده می‌شود.

تمام تصاویر و فایل‌های PDF در کنار صفحات HTML نگه داشته شده‌اند؛ نام فایل‌ها و مسیرهای نسبی را تغییر ندهید.
